# افزونه مرکز اعضای پروشات (Proshot Member Center)

افزونه اختصاصی وردپرس جهت مدیریت اعضا، کارت دیجیتال عضویت، اعتبارسنجی بارکد QR متحرک ضد کپی و کنترل تردد در ۵ شعبه باشگاه ورزشی پروشات (`proshotfit.ir`).

---

## شعب پشتیبانی شده

1. **پرمیوم (Premium)** — `premium`
2. **پلاس آقایان (Plus Men)** — `plus-men`
3. **پلاس بانوان (Plus Women)** — `plus-women`
4. **استاندارد آقایان (Standard Men)** — `standard-men`
5. **استاندارد بانوان (Standard Women)** — `standard-women`

---

## ویژگی‌های اصلی

- **احراز هویت بدون گذرواژه (SMS OTP)**: ورود اعضا صرفاً با شماره موبایل و کد یکبار مصرف، بدون دغدغه فراموشی رمز عبور.
- **کارت دیجیتال عضویت**: طراحی مدرن و کاملاً راست‌چین (RTL-first) با رنگ‌بندی اختصاصی برای اعضای پرمیوم و عادی.
- **بارکد QR متحرک و امن**:
  - امضا شده با کلید امنیتی سرور (HMAC-SHA256).
  - مدت اعتبار ۳۰ ثانیه با تازه‌سازی خودکار هر ۲۵ ثانیه.
  - ثبت یکبارمصرف (Nonce) در دیتابیس برای جلوگیری از ارسال اسکرین‌شات و تقلب.
- **سامانه پذیرش پرسنل (Staff Check-in)**:
  - اسکن فوق‌سریع بارکد یا جستجو با شماره موبایل/نام/کد ملی.
  - اعتبارسنجی بلادرنگ اشتراک، تاریخ اعتبار و شعبه مجاز.
  - جلوگیری از ثبت ورود تکراری در همان روز تقویمی.
  - قابلیت ثبت ورود دستی با ذکر دلیل در صورت بروز اختلال یا عدم دسترسی (Manual Override).
- **تقویم و ارقام شمسی**: نمایش تاریخ‌ها به صورت شمسی و با ارقام فارسی (۱۴۰۴/۰۱/۰۱) و ذخیره‌سازی استاندارد UTC در پایگاه داده.
- **ایمپورت و همگام‌سازی CSV**: بارگذاری مستقیم فایل اکسل/CSV خروجی نرم‌افزارهای باشگاه و همگام‌سازی اعضا و اشتراک‌ها.
- **لاگ امنیتی کامل (Audit Trail)**: ثبت تمام رویدادها شامل ورود کاربر، اعتبارسنجی‌ها و ورودهای دستی.

## نحوه نصب و راه‌اندازی در وردپرس

1. پوشه `proshot-member-center` را در مسیر `wp-content/plugins/` هاست وردپرس کپی نمایید.
2. از منوی **افزونه‌ها** در پیشخوان وردپرس، افزونه **Proshot Member Center** را فعال کنید. (جداول اختصاصی دیتابیس و نقش‌های کاربری به طور خودکار ایجاد می‌شوند.)
3. دو برگه جدید در وردپرس ایجاد کنید:
   - برگه **پورتال اعضا** (مثلاً در آدرس `proshotfit.ir/member/`) با قرار دادن کد کوتاه:
     ```text
     [proshot_member_portal]
     ```
   - برگه **پذیرش پرسنل** (مثلاً در آدرس `proshotfit.ir/member-center/check-in/`) با قرار دادن کد کوتاه:
     ```text
     [proshot_staff_checkin]
     ```
4. تنظیمات سرویس پیامک و کلیدهای کاوانگار را از منوی **باشگاه پروشات > تنظیمات** پیکربندی نمایید.

## ساختار دیتابیس (جداول با پیشوند `wp_ps_`)

| جدول | کاربرد |
|---|---|
| `ps_branches` | اطلاعات و خط‌مشی ۵ شعبه باشگاه |
| `ps_members` | مشخصات فردی اعضا، شماره نرم‌افزار باشگاه، اتصال به کاربر وردپرس |
| `ps_memberships` | وضعیت اشتراک (فعال، منقضی، فریز، معلق)، تاریخ شروع و پایان |
| `ps_member_branch_access` | مجوزهای صریح دسترسی به شعب |
| `ps_attendance` | سوابق ورود تأیید شده، رد شده و ورودهای دستی |
| `ps_qr_nonces` | توکن‌ها و نانس‌های بارکد QR متحرک |
| `ps_devices` | دستگاه‌های مجاز پذیرش و کیوسک |
| `ps_sync_jobs` | صف فرایندهای همگام‌سازی و ایمپورت |
| `ps_sync_conflicts` | تعارضات داده‌ای جهت بررسی مدیریت |
| `ps_notifications` | اطلاعیه‌های اختصاصی شعب برای اعضا |
| `ps_audit_logs` | لاگ امنیتی کلیه عملیات‌های سامانه |
| `ps_otp_codes` | کدهای تأیید پیامکی موقت و هش شده |

## توسعه فرانت‌اند

فرانت‌اند با **React 19**، **TypeScript** و **Tailwind CSS v4** پیاده‌سازی شده و از طریق **Vite** بیلد می‌شود:

```bash
cd proshot-member-center
npm install
npm run build
```
فایل‌های خروجی مستقیماً در پوشه `assets/` افزونه تولید شده و توسط اسکریپت‌لودر وردپرس فراخوانی می‌شوند.
